# Monitor Rook Credits

> For the full site index for AI agents, see [llms.txt](https://www.testmuai.com/support/docs/llms.txt).

The current Rook command surface does not provide a /budget command. The TUI status bar shows the account balance and how many credits the current session has spent. Use /plan for the authenticated account and available balance.

Model-backed phases report what they spend. Rook checks credit boundaries between calls and preserves completed local work when credits are exhausted.
