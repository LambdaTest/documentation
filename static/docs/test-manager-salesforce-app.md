# How to Generate and Run Salesforce Test Cases with Test Manager

> For the full site index for AI agents, see [llms.txt](https://www.testmuai.com/support/docs/llms.txt).

The Test Manager app for Salesforce is an AI test case generator that you install inside Salesforce. It reads the flows already configured in your Salesforce org and generates manual test cases for them, so a Salesforce professional can build a test suite and run it without writing test cases from scratch.

This app is available through Salesforce AgentExchange and requires a TestMu AI **Test Manager** license. The app itself is free to install. To enable it for your organization, reach out to your account manager or email [support@testmuai.com](mailto:support@testmuai.com).

## How It Works

The app is organized as a three-level tree:

- **Test Suite:** A collection of the test cases created for one Salesforce flow. You create a suite by naming it, selecting the flow to test, and providing the business logic.
- **Test Case:** An individual test generated by AI. Each test case has a name, test steps, and an expected result, and can be edited after generation.
- **Test Run:** The unit used to execute a suite's test cases. Opening a test run redirects you to the TestMu AI platform, where the tests and configuration are preloaded.

The flows themselves are not a fixed set. The app dynamically captures the flows configured in your Salesforce org, so the available flows reflect what your team has built.

## Prerequisites

- A Salesforce account with the flows you want to test.
- The Test Manager app installed from Salesforce AgentExchange (see below).
- A TestMu AI **Test Manager** license and a **HyperExecute** license.

## Install the App

The Test Manager app is published on Salesforce **AgentExchange** and is free to install.

**Step 1:** Install the **Test Manager** app into your Salesforce org from AgentExchange.

**Step 2:** Open the **App Launcher** in Salesforce.

**Step 3:** Search for **Test Manager** and open **TestMu Test Manager**.

## Create a Test Suite and Generate Test Cases

**Step 1:** In Test Manager, click **New Test Suite**. You can start a new suite directly from the home screen without opening the Test Suite section first.

**Step 2:** Enter a name for the suite, for example `Demo Suite 01`.

**Step 3:** Select the Salesforce **flow** you want to test, along with its **version**. You can also select an obsolete version of a flow.

**Step 4:** Enter the **business logic** for the flow. This is free text that describes what the flow does. You can include data such as credentials here, and the AI picks it up when generating test cases.

**Step 5:** Click **Generate Test Cases (AI)**.

The AI reads the flow, applies your business logic, and generates test cases, typically three to five per suite. More detailed business logic produces more scenarios. Each generated test case includes a name, test steps, and an expected result.

Once generation completes, the suite appears with its details, flow, and business logic.

## Review and Edit Test Cases

To change a generated test case, open it and click **Edit**, or use the pencil icon next to **Test Steps**, then update the steps.

All generated test cases are also listed in the **Test Cases** section, and the suite's test run is listed in the **Test Runs** section, named after the suite.

Any IDs or credentials in generated steps (for example, `user.expired@example.com`) are placeholder values and do not have access to your Salesforce data. Provide real values through the business logic field. Full test data management is not part of the Salesforce app.

## Configure the App

Open the **Configuration** section. Three settings control how the app connects and where test cases run:

- **Check Connection:** Verifies that the app is integrated with the TestMu AI platform.
- **Test Manager Project:** The TestMu AI Test Manager project your generated test cases are saved to.
- **Default Configuration:** The OS, browser, and resolution combination your test runs use.

To set up a default configuration, open **Test Manager > Configurations** on the TestMu AI platform and create a configuration (for example, name it `Firefox` with Windows 10, Firefox, and your preferred resolution). Back in the app, refresh to fetch the new details, then select the configuration from the dropdown. Every test run created after a suite is created inherits this configuration.

## Run Test Cases

Each suite has a **Test Run** named after the suite. Open it and click the link to launch the run on the TestMu AI platform, where your test instances and configuration are already loaded.

On the platform, click **Run Test Instances**. The platform allocates a machine and opens the Salesforce application. Currently the app supports **manual test cases** only, that is, ordered steps with no automation script. Step through each instance manually and mark each step as passed or failed before moving to the next one.

### Automate a Test Case

To automate a manual test case, open it from the **Test Manager** link and click **Automate with KaneAI**. This opens a KaneAI session pre-filled with the test steps, where you author the automated test and then execute it on HyperExecute.
