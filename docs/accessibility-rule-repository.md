# Accessibility Rule Repository

Browse every accessibility rule TestMu AI checks, grouped by platform. Each rule is a standalone section with its WCAG mapping, what it checks, why it matters, common failures, and how to fix.

- **[Web Accessibility Rules](/support/docs/accessibility-web-rules/)** — 37 rules mapped directly to WCAG success criteria.
- **[Android Accessibility Rules](/support/docs/accessibility-android-rules/)** — 34 rules covering TalkBack behavior.
- **[iOS Accessibility Rules](/support/docs/accessibility-ios-rules/)** — 33 rules covering VoiceOver behavior.
